Connect coding agents such as **Bob (IBM)** and **Claude Code** to a Portals instance so they can build and run flows over MCP.

This page describes the <Icon name="Terminal" aria-hidden="true"/> **Portals MCP Client** entry in **Settings**. It is different from Portals's other MCP options.

* [**Use Portals as an MCP client**](/mcp-client): Use the **MCP Tools** component in flows so agent components _on the canvas_ can call external MCP servers or Portals MCP URLs.
* [**Use Portals as an MCP server**](/mcp-server): Use the **MCP Servers** page in Portals to expose your Portals project as an MCP server to desktop clients such as Cursor or Windsurf.

## Connect Bob (IBM) or Claude Code

To connect Portals to a coding agent, do the following:

1. Click your profile icon, select **Settings**, and then click <Icon name="Terminal" aria-hidden="true"/> **Portals MCP Client**.
2. Select the coding agent you want to connect to Portals, and follow the steps shown in the UI.

    All client configurations run `px-mcp` with `uvx`, and set `LANGFLOW_SERVER_URL` to your Portals server URL and `LANGFLOW_API_KEY` to a Portals API key of your choice.

    * To connect to **Bob (IBM)**, paste the configuration JSON into `~/.bob/settings/mcp_settings.json`, or use **Edit Project MCP** for a project-only setup.
    * To connect to **Claude Code**, run the `claude mcp add` command shown on the page, or manually add the JSON configuration to `~/.claude.json`.

    If you do not set `LANGFLOW_API_KEY`, the coding agent can log in with the Portals username and password you use to sign in to the Portals web UI for that server.
