There are several ways you can interact with the Portals community and learn more about the Portals codebase.

## Join the Portals Discord server

Join the [Portals Discord Server](https://discord.gg/EqksyE2EX9) to ask questions and showcase your projects.

## Follow Portals on X

Follow [@portals_ai](https://twitter.com/portals_ai) on X to get the latest news about Portals.

## Star Portals on GitHub

If you like Portals, you can star the [Portals GitHub repository](https://github.com/portals-ai/portals).
Stars help other users find Portals more easily, and quickly understand that other users have found it useful.

Because Portals is open-source, the more visible the repository is, the more likely the codebase is to attract [contributors](/contributing-how-to-contribute).

## Watch the GitHub repository

You can watch the [Portals GitHub repository](https://github.com/portals-ai/portals) to get notified about new releases and other repository activity.

To get release notifications only, select **Releases only**.

If you select **Watching**, you will receive notifications about new releases as well as issues, discussions, and pull requests, if you are interested in that activity.
For information about customizing repository notifications, see the [GitHub documentation on repository subscriptions](https://docs.github.com/en/account-and-profile/managing-subscriptions-and-notifications-on-github/managing-subscriptions-for-activity-on-github/viewing-your-subscriptions).

## Request enhancements and get help through GitHub

You can also submit feature requests and get help with Portals through the GitHub repository.
For more information, see [Get help and request enhancements](/contributing-github-issues).
