# LTX Video Generation

## Overview

Cinematic Canvas integrates the **Lightricks LTX-Video** model to generate high-quality, 5-second video clips from text prompts. This capability is hosted on a dedicated, auto-scaling Google Cloud infrastructure to ensure performance and cost-efficiency.

## Key Capabilities

*   **Cinematic Quality**: Generates high-fidelity video at 768x512 resolution (configurable).
*   **Temporal Consistency**: Optimized for smooth motion and coherent physics.
*   **Prompt Adherence**: Closely follows the detailed "Meta-Prompts" generated by the Director and Cinematographer agents.
*   **Safety**: Integrated with First AD safety checks to prevent generation of harmful content.

## Integration in Workflow

The LTX model is accessed by the `SceneGeneratorAgent` during the **Production Phase**.

1.  **Meta-Prompting**: The system aggregates inputs from all roles (Director, Gaffer, etc.) into a single, optimized prompt.
2.  **Request**: The prompt is sent to the LTX service via a secure API call.
3.  **Generation**: The service generates the video (approx. 45-60s per clip).
4.  **Storage**: The result is uploaded to GCS and registered in the Asset System.

## Infrastructure

The LTX service runs on **NVIDIA L4 GPUs** within a Google Cloud Managed Instance Group (MIG).

*   **Auto-Scaling**: Scales from 0 to N instances based on queue depth.
*   **Global Access**: Served via a Global Load Balancer.
*   **Cost Efficiency**: Scales to zero when not in use.
