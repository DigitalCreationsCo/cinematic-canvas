## Resilient World-Building

Last week, we focused on centralizing the API and establishing a decentralized asset store architecture, empowering the node-based canvas UI with improved state management and polymorphic media tracking.

As the canvas expanded to handle larger storyboards, two new challenges emerged: preventing cross-session layout drift during real-time collaboration, and creating a cohesive way to reference world entities within scenes without heavy dropdowns. This week, we doubled down on the robustness of the spatial workspace by implementing dual-tier layout persistence and a seamless mention system.

The introduction of `HybridNodeStorage` alongside the new Entity Mention System radically improves the resilience of the canvas while enabling a frictionless, context-aware writing experience.

### What is Cinematic Canvas?
Cinematic Canvas is the generative AI workspace for storytelling. Built by and for creators, the platform treats story elements as structured primitives, providing unparalleled control over cinematic worlds with persistent character and narrative continuity. It operates under the constraints of maintaining professional cinematic output while offering an intuitive node-based graph interface.

**Tech Stack**: React (Vite), Zustand, Tailwind CSS, `@xyflow/react`, Node.js, LangGraph, Supabase (PostgreSQL), IndexedDB.

## 1. Dual-Tier Layout Persistence & OCC Recovery
The shift to a visual node-based workflow requires instantaneous layout updates while maintaining a reliable source of truth in the cloud. We implemented **Dual-Tier Layout Persistence** using the new `HybridNodeStorage` adapter.

* **Local-First Speed**: All node movements are instantly debounced and written to IndexedDB, ensuring a zero-latency feel and offline capability.
* **Cloud Syncing**: Changes are asynchronously synced to Supabase using real-time Postgres changes.
* **OCC Auto-Recovery**: To prevent layout version drift, we hardened the Optimistic Concurrency Control (OCC) logic. In the event of a cross-session conflict, the client now intercepts the error, automatically refreshes the layout from the server, and recovers seamlessly.

![Clean technical diagram, Big Tech aesthetic, black and grey, showing data flow from local cache to cloud database](/images/2026-03-25-hybrid-storage.png)
*Data flows instantly to IndexedDB and synchronizes with Supabase using Server-Wins OCC.*

**Direct Benefit:** You can pan, zoom, and organize massive storyboards without fear of data loss, even during network blips or when collaborating across multiple devices.

## 2. Intelligent Entity Mentions System
Writing scenes often requires referencing characters and locations. We built a comprehensive **Entity Mention System** to replace clunky forms and manual linking.

* **Tag Registry Service**: A backend service that manages globally unique `@handle` identifiers across the project and world scope, guarded by strict Role-Based Access Control (RBAC).
* **KBHydrator**: A backend hydrator that intercepts mentions, validates trace IDs, and retrieves structured entity metadata before LLM generation.
* **Local-First Mention Extension**: Powered by Tiptap, the editor caches suggestions client-side for zero-latency typing, dynamically inserting visual spans when a valid entity is tagged in the scene description.

![Clean technical diagram of a text editor typing an @handle, resolving against a tag registry database](/images/2026-03-25-entity-mentions.png)
*The MentionExtension resolves @handles against a cached TagRegistry, hydrating context before LLM generation.*

**Direct Benefit:** You can seamlessly weave characters and locations directly into your scene descriptions with a few keystrokes, knowing the engine will perfectly maintain their visual continuity.

## 3. Drag-and-Drop Interactive Media Canvas
A modern workspace should feel tactile. We upgraded the canvas interaction model to support direct media manipulation.

* **File Ingestion**: Implemented a unified drop zone. Dropping images instantly creates Location or Character nodes, while dropping audio tracks triggers the new `AudioPlayer` component.
* **Single-Audio Enforcement**: The integrated `AudioPlayer` ensures only one track plays at a time across the entire app, automatically pausing previous tracks to prevent chaotic overlapping playback.
* **Lock-Animation System**: We developed a JS-driven animation lock for UI buttons. By leveraging `CSSAnimation` tracking, keyframe animations play fully through even if a hover state is canceled prematurely, keeping the interface feeling snappy and intentional.

![UI schematic showing a file being dropped onto a canvas node, triggering an audio waveform player](/images/2026-03-25-interactive-media.png)
*Audio and image file drops instantiate new interactive nodes directly within the DAG.*

**Direct Benefit:** Import reference material and soundscapes by simply dragging them onto the canvas, keeping you immersed in the creative flow.
