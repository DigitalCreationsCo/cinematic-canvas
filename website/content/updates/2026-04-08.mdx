## What is Cinematic Canvas?

**Cinematic Canvas** is the generative AI workspace for storytelling. It treats story elements—characters, locations, scenes, and style references—as structured primitives, giving creators total control over building cinematic worlds with strict visual and narrative continuity.

**Technology Stack:** React (Vite) · Zustand · Tailwind CSS · `@xyflow/react` · Node.js · LangGraph · PostgreSQL · IndexedDB

## What's New

## 1. Team Authorization Middleware

Cinematic Canvas now enforces strict team-scoped authorization across every API route. Users can only access resources—projects, worlds, entities, pipelines—belonging to their active team context. This ensures workspace isolation in multi-tenant environments where multiple teams share the infrastructure.

- **Cached Authorization**: Team authorization is cached per request to avoid redundant database queries. High-traffic routes check authorization once and short-circuit subsequent checks.
- **Cross-Team Isolation**: Project-scoped routes now validate that the requesting user belongs to the owning team. Unauthorized requests are rejected before touching any workflow state.
- **Secure Route Guards**: All protected routes—entity CRUD, pipeline execution, asset access—now validate team membership via the middleware stack.

![Authorization flow diagram showing user, team context, route guards, and resource isolation](/public/images/2026-04-08-authorization-diagram.png)
*Team context flows from authentication through middleware to resource access—isolation enforced at every layer. Each request validates team membership before allowing data access.*

**The Result:** Cinematic Canvas is now truly multi-tenant. Teams can collaborate on shared worlds without fearing cross-team data leakage. The security model matches the collaborative ambition.

## 2. Intelligent @Mentions

The @mention system has been completely rebuilt with a native contentEditable implementation—eliminating the Tiptap editor dependency entirely. Characters, locations, and scenes now link intelligently across the workspace using the same @mention pattern found in modern collaborative tools.

- **Native DOM Extraction**: Mentions now extract via DOM traversal instead of Tiptap AST parsing. This removes the fragile dependency on editor internals and makes the mention system portable across any editable surface.
- **Auto-Fill Integration**: Characters and locations auto-populate when typing @mentions in scene description fields. Start typing @ and the autocomplete dropdown suggests entities from your world.
- **Dialog Integration**: @Mentions are integrated into all editable dialogs—scene editors, entity detail panels, pipeline configuration—providing consistent cross-entity linking.
- **Auto-Register Handles**: Mention handles are auto-registered on entity creation. New characters and locations are immediately searchable via @mentions without manual registration.

![Mention system diagram showing autocomplete, DOM extraction, entity linking, and dialog integration](/public/images/2026-04-08-mentions-diagram.png)
*Mentions flow from autocomplete selection through DOM extraction to entity linking—native implementation without editor dependencies. Characters, locations, and scenes link seamlessly across the workspace.*

**The Result:** The workspace feels like a modern collaboration tool. Writers can weave characters and locations into scenes by typing @mentions, with full autocomplete and persistent linking. Narratives stay connected.
