## From Monolith to Micro-Services: A New API and Asset Architecture

Last week, we laid the groundwork for the new node-based canvas UI. This week, we're continuing that work by refactoring our API and asset management systems to be more modular, scalable, and maintainable.

The previous monolithic architecture was becoming a bottleneck. By centralizing our API routes and decentralizing our asset management, we're setting the stage for a more robust and feature-rich platform.

This sprint was all about paying down technical debt and building a solid foundation for the future of Cinematic Canvas.

### Project Overview
Cinematic Canvas is a generative media product that enables structured storytelling and directorial agency using AI. Our mission is to provide creators with the tools they need to bring their visions to life, without being constrained by the limitations of traditional video production.

Our technology stack includes Next.js, React, Drizzle, PostgreSQL, and a suite of AI models for video and image generation.

#### What's New

### 1. Centralized API Routes
We've implemented a new centralized API routing system that uses a function-based accessor pattern. This makes our API more type-safe, easier to maintain, and simpler to use.

**Before:**
```typescript
// Hardcoded API paths
const response = await fetch('/api/projects/123/scenes');
```

**After:**
```typescript
import { api } from '~/lib/api';

// Type-safe and centralized
const response = await api.projects('123').scenes.get();
```

![A clean, 'Google Cloud' style diagram showing a centralized API gateway routing requests to different microservices.](/images/2026-03-18-api-diagram.png)
*The new centralized API gateway acts as a single point of entry for all client requests, simplifying the client-side code and improving maintainability.*

**Direct Benefit:** This change simplifies the client-side code, reduces the chance of errors, and makes it easier to add new API endpoints in the future.

### 2. Advanced Asset Management
Our new decentralized asset management system is a major step forward. We've introduced a decentralized asset store architecture, polymorphic media reference counting, and a like/dislike feedback mechanism for asset versions.

**Key Features:**
*   **Decentralized Stores:** Each asset type now has its own dedicated Zustand store, improving performance and scalability.
*   **Reference Counting:** We now track how many times each asset is used, which will allow us to implement more intelligent asset cleanup and garbage collection in the future.
*   **Feedback Mechanism:** You can now like or dislike asset versions, providing valuable feedback to the system and helping us improve the quality of our generated assets.

![A 'Google Cloud' style diagram illustrating the new decentralized asset management system, with different asset types (images, videos, etc.) being managed by separate stores.](/images/2026-03-18-asset-diagram.png)
*The new decentralized asset management system provides a more scalable and performant way to manage assets, with each asset type being handled by a dedicated store.*

**Direct Benefit:** This new system is more performant, scalable, and provides a better user experience. The feedback mechanism will help us improve the quality of our generated assets over time.

### 3. Canvas UI Enhancements
We've made a number of improvements to the new node-based canvas UI, including a new metadata inspector, improved node handle styling, and a confirmation dialog for node removal.

**Key Enhancements:**
*   **Metadata Inspector:** You can now view and edit the metadata for any node on the canvas, including the world and project settings.
*   **Improved Node Handles:** The node handles have been restyled as overflow scrubbers with a unified entry/exit appearance, making them easier to use.
*   **Confirmation Dialog:** To prevent accidental deletions, we've added a confirmation dialog that appears when you try to remove a node from the canvas.

![A 'Google Cloud' style diagram showing the new metadata inspector in the canvas UI, with tabs for 'World' and 'Project' settings.](/images/2026-03-18-canvas-diagram.png)
*The new metadata inspector provides a convenient way to view and edit the settings for any node on the canvas.*

**Direct Benefit:** These enhancements make the canvas UI more powerful, intuitive, and safer to use.
