# Dark skeuomorphic system diagram style

Use a skeuomorphic dark UI diagram aesthetic for the 3 technical graphics.

## Color and surface treatment

- Deep navy or near-black background in the `#0a0f1e` range
- Component cards with rounded rectangle borders in glowing teal / cyan around the `#00e5c8` range
- Soft cyan inner glow on card edges
- Dark card fills around the `#0d1a2a` range
- White or near-white sans-serif labels
- Small teal iconography inside cards
- Secondary labels, such as protocol names or sub-labels, in muted teal with lighter weight

## Structure

- Use a horizontal or left-to-right flow layout
- Group related components into labeled rectangular sections with rounded corners and a faint border
- Connect sections and sub-components with directional arrows
- Make each node a rounded card with an icon and a label
- Use pass / deny branching where the logic calls for it
- Set section headers in uppercase sans-serif teal
- Set node labels in white, sentence case
- Put protocol or type sub-labels below the icon in small muted teal text

## Quality bar

- Keep the graphics informative and clear
- Do not make them dense or overwhelming
- Favor polished vector-style output
- Use error-free English text
- Do not mention "Google"
